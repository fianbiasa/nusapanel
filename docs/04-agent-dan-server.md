# 4. Agent & Layout Server

## 4.1 Struktur kode agent (Go)

Tanda ✅ = sudah ada (P0); sisanya menyusul sesuai fase.

```
agent/
├── cmd/
│   ├── rayxod/          ✅ daemon agent
│   └── rayxo/        ✅ CLI (ping, call <method> [params], rebuild)
├── internal/
│   ├── rpc/            ✅ server JSON-RPC, socket, cek UID pemanggil, registry method, kunci per akun
│   ├── peercred/       ✅ UID pemanggil dari kernel (SO_PEERCRED di Linux, LOCAL_PEERCRED di Mac)
│   ├── client/         ✅ klien socket (dipakai rayxo dan test)
│   ├── actions/        ✅ daftar method; menyusul satu paket per namespace: account, web, php, ssl, dns, db, mail, fs, ...
│   ├── sysinfo/        ✅ data untuk system.info (Linux; Mac khusus pengembangan)
│   ├── clock/          ✅ zona waktu server (baca /etc/localtime, ganti lewat timedatectl)
│   ├── reconfigure/    ✅ jalankan ulang setup.sh (--reconfigure) untuk ganti hostname, di unit systemd sendiri
│   ├── panelport/      ✅ coba port panel baru, konfirmasi lewat port itu, tutup otomatis kalau tidak dikonfirmasi
│   ├── validate/       ✅ username, domain, versi PHP; menyusul path dan nilai config
│   ├── version/        ✅ versi, diisi saat build
│   ├── runner/         ✅ jalankan program tanpa shell; menyusul: opsi turun ke UID user
│   ├── sysuser/        ✅ user/grup Linux, folder home & domain tanpa mengikuti symlink
│   ├── webserver/      ✅ vhost Nginx & Apache, pool PHP-FPM: render template, tulis atomik, validasi, reload, rollback
│   ├── isolation/      ✅ tes integrasi: akun tidak bisa membaca file akun lain (dijalankan sebagai root di server)
│   ├── daemons/        brute force monitor, watchdog
│   └── services/       wrapper postfix, API PowerDNS, MariaDB, ...
├── packaging/
│   └── rayxod.service   ✅ unit systemd
└── Makefile            ✅ build (Mac), linux (amd64/arm64 static), isolation (binary tes isolasi untuk server; `ARCH=arm64` untuk arm64), test, vet, check
```

### Menjalankan rayxod

```
rayxod --socket /run/rayxo/agent.sock --allow-user rayxo --socket-group rayxo
```

| Flag             | Default                 | Fungsi                                                   |
| ---------------- | ----------------------- | -------------------------------------------------------- |
| `--socket`       | `/run/rayxo/agent.sock` | Lokasi Unix socket                                       |
| `--allow-user`   | `rayxo`                 | User yang boleh memanggil agent (selain root)            |
| `--socket-group` | `rayxo`                 | Grup pemilik socket; kosong = tidak diubah               |
| `--call-timeout` | `10m`                   | Batas waktu satu panggilan, termasuk menunggu kunci akun |

Socket dibuat dengan izin `0660` (umask ketat saat dibuat, jadi tidak ada celah sebelum izin final). Saat menerima `SIGTERM`, rayxod berhenti menerima koneksi, menunggu panggilan yang sedang berjalan selesai, lalu menghapus socket. Log berformat JSON ke stderr (dibaca journald).

### Protokol

JSON-RPC 2.0, satu koneksi = satu request dan satu response, masing-masing satu baris JSON diakhiri `\n` (maks 1 MiB). `params` selalu objek; field yang tidak dikenal ditolak.

| Kode     | Arti                                                                  |
| -------- | --------------------------------------------------------------------- |
| `-32700` | Request bukan JSON yang valid                                         |
| `-32600` | Request tidak valid (tanpa `jsonrpc`/`method`/`id`, terlalu besar)    |
| `-32601` | Method tidak ada                                                      |
| `-32602` | Params tidak valid                                                    |
| `-32603` | Error internal; detail hanya di log agent, tidak dikirim ke pemanggil |
| `-32000` | Aksi gagal; pesannya aman ditampilkan ke user panel                   |
| `-32003` | Pemanggil tidak diizinkan (dikirim dengan `id: null`)                 |
| `-32004` | Akun sedang dikunci task lain sampai batas waktu habis                |

## 4.2 Aturan validasi (berlaku di semua aksi)

| Input                         | Aturan                                                                                                                                                                                              |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Username                      | `^[a-z][a-z0-9]{2,15}$`; bukan nama tercadang (`root`, `rayxo`, `www-data`, `mysql`, `postfix`, `dovecot`, dll.); belum ada di `/etc/passwd`                                                        |
| Domain                        | Huruf kecil, punycode, maks 253 karakter, setiap label `^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$`, minimal 2 label; bukan hostname server; tidak tumpang tindih dengan domain/subdomain milik akun lain |
| Path                          | Dibersihkan, symlink diresolve, harus di bawah `/home/<user>/`; operasi dijalankan sebagai UID user                                                                                                 |
| Nilai di config               | Tanpa newline, karakter kontrol, atau kutip; tipe & rentang dicek per kunci (contoh: `memory_limit` = angka + `M`/`G`, maksimal sesuai paket)                                                       |
| Perintah cron                 | Disimpan apa adanya, tapi selalu dijalankan sebagai user pemiliknya, tidak pernah sebagai root                                                                                                      |
| Nama service                  | Dari daftar putih                                                                                                                                                                                   |
| File sistem yang boleh diedit | Dari daftar putih                                                                                                                                                                                   |

### db (MariaDB)

Nama database dan user selalu `<username>_<nama>` (`[a-z0-9_]`, database ≤ 64, user ≤ 32 karakter); agent menolak nama tanpa awalan akun itu, jadi satu akun tidak bisa menyentuh database akun lain. User hanya dibuat untuk `localhost`. Panel hanya mengirim hash `mysql_native_password` (`*` + SHA1(SHA1(password)) heksadesimal besar), tidak pernah password-nya. SQL dikirim ke `mariadb` (root lewat unix_socket) melalui stdin.

Setiap akun juga punya **user pemilik** bernama persis `<username>` (tanpa akhiran), dengan akses ke semua database akun itu; phpMyAdmin login sebagai user ini. Password-nya dibuat baru setiap kali phpMyAdmin dibuka dan diganti password acak yang tidak diketahui siapa pun begitu sesinya habis. User ini tidak dihapus selama akunnya ada, karena view, trigger dan routine yang dibuat lewat phpMyAdmin memakainya sebagai DEFINER; user sementara akan membuat objek itu rusak (error 1449) begitu dihapus.

### fs (file manager, semuanya sebagai user)

Setiap aksi dijalankan oleh proses pembantu (`rayxod files-helper`) yang berjalan sebagai uid/gid akun itu dengan grupnya sendiri saja, dan membuka home sebagai `os.Root`: path dan symlink tidak bisa keluar dari `/home/<user>`, dan izin OS menentukan apa yang boleh disentuh.
